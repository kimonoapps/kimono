packages/ui

Icons and marks

Three tiers. Each has one job and is drawn in one place.

1 · The house

The branch

Kimono itself: the header, sign-in, favicon and phone app icon. Ink, never recoloured.

kimono
2 · An app

The bloom

Every app is an id and one colour; the petals, texture and heart come from those. Its mon glyph sits in the dark heart. Used on Home, the rail, Admin and crossings, and nowhere as a decoration.

3 · An action or a row

Line icons

24px, 1.7 stroke, round caps. One set in packages/ui; the phone's Marks.kt is generated from it. In a list row an icon sits in a soft Material shape tinted by role.

What changes in code

From five sources to three

Today
  • packages/ui/glyphs.tsx: 11 mon glyphs
  • components/icons.tsx: AppGlyph redraws notes, play and image a second way, plus Grid and Settings
  • drive/icons.tsx: 28 line icons
  • code/icons.tsx: Drive's set plus 9
  • Marks.kt: the same paths copied by hand (and missing open, which crashes Code)
Proposed
  • Branch: KimonoBranch, unchanged
  • Blooms: BloomMark + glyphs.tsx only; AppGlyph goes
  • Line icons: one icons.ts in packages/ui (Drive + Code + phone names, 5 new), one <Icon>
  • Marks.kt's paths are generated from that file at build time, so the phone can't drift or miss one
